# Restaurant Menu App

## Installation

To run the Restaurant Menu App, follow these steps:

1. Clone the repository:
```
git clone https://github.com/Javadkarami-com/restaurant-menu.git
```

2. Navigate to the project directory:
```
cd restaurant-menu
```

3. Open the `index.html` file in your web browser.

## Usage

The Restaurant Menu App allows you to browse and view details of the available menu items at the restaurant.

- The home page (`index.html`) displays the menu categories and popular dishes.
- Clicking on a menu category or dish will take you to the product details page (`description.html`), where you can view more information about the selected item.
- The location page (`location.html`) provides the restaurant's address, contact information, and a map.
